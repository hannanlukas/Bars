
**Overview**

Bars is a bar chart application created with flutter providing an infinitely scrollable and zoomable dynamic canvas, with built in customisation features to view your data to your desire. Relying entirely on a json config file specified by the launch parameters which provides the initial configuration and bar data, the application can be used across any language to easily view sets of data in a bar chart format.

**Features**

- Settings menu to configure the look and style of the bar chart.
- Sort menu to configure the order of the bars.
- Bar modification menu to hide individual bars and adjust the individual bars colour.
- Bar information menu for providing a description of what the bar chart represents.
- Hover overlay to easily see the values and labels of a specific bar.
- Signed and unsigned X and Y bar values.
- Bar label view for replacing the X value with a specific label.
- Resizable in window bar chart for allowing very large values to be viewed with ease.

**Getting Started**
1. Unzip the package.
2. Create a clone of the config.json and modify it with your desired configuration and bar data.
3. Modify the run.bat to specify the path of the new config.json file.

*Note: The config path must be passed as a string* : `start barchart.exe "...\config.json"`
